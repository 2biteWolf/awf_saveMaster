Version 1.4.2. Opera GX and Chrome extension.

Ultimate tool for explore and save media content in web.

One-click save for images, GIF and video, plus a built-in interface with layered menus and a full settings panel.Chrome and Opera GX.

Point at a picture, GIF or video and press the save key once. The file lands in Downloads, or in a subfolder you set.

The extension brings its own interface, not a single button. Hold the save key and the first menu opens under the cursor: presets, open, copy, save, hotkeys. Hold longer and a second menu takes over for tabs. The viewer is a third layer: history, fit, and save-as for that file. Settings sit behind all of this, so the click stays simple and the rest is adjustable.

Ten presets, rename patterns, PNG or original format, zoom, and wheel tab switching. Image and Video open in the viewer. Right-click stays the normal browser menu. No account. Files and settings stay on your computer.

Features

  • save/copy/open media frow sites with 1 click in custom folder path
  • 10 setting presets fast to switch
  • setting custom hotkeys
  • media viewer with adaptive media scale
  • save image history
  • scrolling browser tabs with mmb
  • zoom media with press mmb

Hotkeys

recommended mouse setup = mouse4=main button & mouse5=ctrl+w - useful setup for massive saving

hotkeys can be changed in popup menu

  • ctrl+k = main button [save/press to menu]
  • alt+z = pin/unpin tab
  • alt+q = open in new tab
  • alt+v = copy content
  • alt+c = alt save button

Install

  • download from chrome web store

OR

  • download repository
  • unzip archive in folder
  • open chrome ext: chrome://extensions/ OR operaGX ext: opera://extensions
  • load unpacked - select repo folder
